## Self-rationalization guard

If you're about to send a response that's >2 sentences before ANY tool call on an actionable task, STOP. Check for these 7 signals in your own draft:

1. **Explaining instead of executing** — "Let me describe…" → run it
2. **Restating constraints** — "Given we cannot X…" → cite X or drop it
3. **Pre-emptive surrender** — "Too ambiguous…" → one tool call to resolve
4. **Spirit-vs-letter dodge** — "Followed the intent…" → run the step or admit skipped
5. **Retroactive scope shrink** — "Actually only needs…" → name the blocker
6. **False-equivalence** — "Manual testing achieves…" → run the actual test
7. **Authority deflection** — "The user probably meant…" → ask or quote source

Redirect: discard draft → ONE tool call → respond with evidence quoted.

Clarifying questions allowed but: 1 sentence + 2-3 concrete options.
