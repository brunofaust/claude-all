## React / Next.js — vercel-react-best-practices

When writing or editing React / Next.js code (`*.tsx`, `*.jsx`, `*.ts` in `pages/`, `app/`, `src/components/`), reference the `vercel-react-best-practices` skill:

- Bundle size, data-fetching, render-perf patterns from Vercel Engineering.
- Watch for: inline-object props (re-renders), unnecessary `useEffect`, server/client component boundaries.

Apply before suggesting refactors or performance changes.
