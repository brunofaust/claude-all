## Bash safety — credential leaks & destructive writes

- **🔴 `Bash(PGPASSWORD=... psql ...)` — CREDENTIAL LEAK.** Inline DB passwords end up in transcripts, logs, and memory. RDS → `rds-postgres-query` (Secrets Manager / IAM auth). Other Postgres → `postgres-query`. If you find yourself typing `PGPASSWORD=`, back out and delegate.
- **🔴 `Bash(curl -H "Authorization: Bearer <token>" ...)` — CREDENTIAL LEAK.** PATs / API keys / Slack tokens land in the transcript verbatim. GitHub → `gh` CLI via `gh-runner`; other APIs → load the secret at point of use, never inline it.
- **🔴 `Bash(TOKEN=$(aws secretsmanager get-secret-value ...))` / `--output text` — CREDENTIAL LEAK.** Both forms print the value. Use `secrets-fetcher` (returns ARN + JSON key names only). If a downstream process needs the value, use the agent that already sources it inline + scoped to one process (e.g. `rds-postgres-query`).
- **🔴 Postgres `INSERT`/`UPDATE`/`DELETE`/`TRUNCATE`/`ALTER`/`DROP`/`COPY` in main-session bash** requires EXPLICIT user confirmation ("yes update X", "confirm UPDATE on Y") AND must be the scripted last step of a pre-declared scenario — never improvised.
- **🔴 Wrapping a destructive AWS call in a `python3 << 'PY' ... PY` heredoc** (`dynamodb delete-item`, `secretsmanager get-secret-value`, …) to bypass the dispatch rule is a guard-bypass anti-pattern. Delegate the OPERATION to its agent — the agent does the same shell work with confirmation + redaction baked in.
- **`Bash(sleep N && cmd)` with a leading sleep is BLOCKED by the harness.** Use `until <check>; do sleep 2; done && cmd`, or `run_in_background: true` + wait for the completion notification. Never chain shorter sleeps to work around it.
- **Sequential exploratory bash calls** are each a process spawn + token-heavy — batch them in your head, then issue one tool call.
- **Agent-first + never bypass on a first auth failure** — rules live in the `tool-dispatch` snippet ("Self-check before raw Bash"): if an agent exists for the command class, delegate; on its auth/SSO failure, fix the precondition and RE-INVOKE the agent, never improvise raw bash.
